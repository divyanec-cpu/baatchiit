Want it as an app icon?

  1. Open baatchiit.vercel.app in Chrome.
  2. Tap Install app on the welcome screen — or Chrome's ⋮ menu → Install app.
  3. It lands on your home screen and updates itself.

Or download the Android file

Only needed if the step above doesn't work on your phone.

Download APK (0.9 MB)
  1. Tap the downloaded file.
  2. Android will warn that it's from an unknown source — choose Settings and allow installs from Chrome, then go back.
  3. Tap Install, then allow the microphone the first time you speak.

This file does not update itself. When a new version comes out you'll need to download it again — the browser version above never has this problem.
